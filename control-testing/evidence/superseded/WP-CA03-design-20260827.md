      - run: pytest -q
      - name: prove non-editable install carries the rule data
        run: |
          pip uninstall -y aiact-triage
          pip install .
          cd /tmp && python -c "import aiact_triage.rules as r; r.timeline(); print('packaged data ok')"

**Executed.** 2026-08-27, 12:20 BST.

**Conclusion.** Design effective: all three required elements are present as
specified. `on: push:` and `pull_request:` carry no branch or path filter, so
every push to any branch and every pull request triggers the workflow, which is
wider coverage than the control objective requires; the matrix runs
`["3.11", "3.12"]`, both versions the package declares support for under
`requires-python = ">=3.11"`; and `pytest -q` runs the full suite after
`pip install -e ".[dev]"`, with no path or marker filter that would narrow what
executes. Whether the control operated is the operating test and is not
addressed here.
