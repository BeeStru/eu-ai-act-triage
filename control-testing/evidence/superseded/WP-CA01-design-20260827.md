# WP-CA01-design-20260827

**Control.** CA-01, version control over all source, rule data and documentation.

**Test method and reason.** Inspection, because design effectiveness is assessed
by inspecting configuration and documents rather than by observing operation.
Two inspections per PLAN.md section 4: author identity over the commit
population for attributability, and reconciliation of the tracked file list
against the contents of a clean non-editable install, to confirm that
everything shipped to a user is under version control. No deviation from the
method as written; the venv path is a session scratchpad directory rather than
`/tmp`, which the sandbox denied.

**Population and regime.** Not applicable, design test. The object under test is
a fresh clone of `https://github.com/beestru/eu-ai-act-triage` taken at

`7aab9f95065f9cf69cbdefe5a9aed64c361386ce`, 45 commits, tags v0.1.0 to v0.5.0.

omitted, and every commit in the population carries an author identity

latter being the commit made through the GitHub web interface at 11:56 BST on
2026-08-27 with GitHub as committer; whether that constitutes consistent author
identity across the population is CA-01's operating test and is deferred to
WP-CA01-operating, not resolved here.
