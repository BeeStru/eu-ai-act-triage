# WP-CA10-design-20261011

**Control.** CA-10, independent review of changes (segregation of duties).

**Test method and reason.** Inquiry plus inspection, per PLAN.md section 4.
Inquiry is legitimate here because the control's absence is a structural
fact about a sole-maintainer repository that no configuration artefact can
contradict, and the inquiry is of the maintainer, who is also the tester, a
limitation the independence paragraph of the memo already covers.
Inspection: the contributor list and any self-merged pull requests.
Deviations, three: (1) the contributor list is taken from author and
committer identities in the fresh clone, because the GitHub contributors API
is unreachable from this sandbox (`gh` and outbound HTTP unavailable);
(2) pull-request history is evidenced from the repository activity feed and
the CI run list captured outside the sandbox by B. Struve on 11 October 2026
and committed in 9b60dc2, `WP-CA03-operating-20261011-activity.jsonl` and
`WP-CA03-operating-20261011-runs.json`, not from the pull-requests API;
(3) the inquiry is evidenced by the maintainer's own written statement in
PLAN.md section 4, shown in the last block of the output below; no separate
oral inquiry took place in this session. No venv was created.
