# WP-CA07-design-20261011

**Control.** CA-07, rule-data citation and verification-date discipline.

**Test method and reason.** Inspection of one rule-data file for the three
elements PLAN.md section 4 names: a metadata block with sources, the
verification-date field, and citation fields on the rules. Inspection is the
method because the control's design is the data convention itself. Selection
of the one file: `timeline.json`, the only file in which all three elements
can be inspected together, because the repository's convention as README
line 105 states it records the rule set's verification date in the timeline
data alone; the other five files carry a metadata block but by design no date
field (declared in STATE.md, 16 July 2026). In this file the citation field
on each rule is `provision`. No deviation. No venv was created; the Python
one-liner runs on the system interpreter in isolated mode.

**Population and regime.** Not applicable, design test. The object under test is
a fresh clone of `https://github.com/beestru/eu-ai-act-triage` taken at
2026-10-11 11:31:07 UTC, `main` at commit
`7aab9f95065f9cf69cbdefe5a9aed64c361386ce`.

in full:
