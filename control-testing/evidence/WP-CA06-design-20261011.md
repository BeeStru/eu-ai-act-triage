# WP-CA06-design-20261011

**Control.** CA-06, zero-runtime-dependency policy.

**Test method and reason.** Inspection of `pyproject.toml` and the README
claim, because the design of a dependency policy lives in the declared
configuration that a `pip install` obeys: the `dependencies` array decides
what an install pulls in, and the README states the policy to users. Per
PLAN.md section 4. No deviation. No venv was created for this test, so the
scratchpad venv deviation recorded in session one does not arise.

**Population and regime.** Not applicable, design test. The object under test is
a fresh clone of `https://github.com/beestru/eu-ai-act-triage` taken at
2026-10-11 11:31:07 UTC for fieldwork session two, `main` at commit
`7aab9f95065f9cf69cbdefe5a9aed64c361386ce`, the scope-freeze commit.
