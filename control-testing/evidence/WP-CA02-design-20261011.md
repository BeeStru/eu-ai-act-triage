# WP-CA02-design-20261011

**Control.** CA-02, protected main branch.

**Test method and reason.** Inspection of the branch-protection settings,
because design effectiveness of a configuration control is assessed by
inspecting the configuration itself. PLAN.md section 4 requires two evidence
items: a full-window screenshot with URL bar and system clock visible, and the
output of `gh api repos/beestru/eu-ai-act-triage/branches/main/protection`.
Deviation, material: neither could be captured in the execution environment.
`gh` is present but not authenticated, and outbound HTTP other than
`git clone` is unavailable in this sandbox, so both items were captured by
B. Struve outside the sandbox on 11 October 2026 and entered in the slots
below before the workpaper was first committed, since PLAN.md section 6
forbids editing a workpaper after commit. The conclusion rests on those two
items only.

**Population and regime.** Not applicable, design test. The object under test is
a fresh clone of `https://github.com/beestru/eu-ai-act-triage` taken at
2026-10-11 11:04:37 UTC, `main` at commit
`7aab9f95065f9cf69cbdefe5a9aed64c361386ce`; the setting under inspection is
server-side and has no representation in the cloned tree.

**Procedure executed.**
```
gh api repos/beestru/eu-ai-act-triage/branches/main/protection
```

**Evidence.**

In-sandbox attempt, the command PLAN.md specifies:
```
=== gh api repos/beestru/eu-ai-act-triage/branches/main/protection ===
To get started with GitHub CLI, please run:  gh auth login
Alternatively, populate the GH_TOKEN environment variable with a GitHub API authentication token.
EXIT: 4
```

Slot 1, `gh api` output, captured outside the sandbox by B. Struve:
```
{
  "message": "Branch not protected",
  "documentation_url": "https://docs.github.com/rest/branches/branch-protection#get-branch-protection",
  "status": "404"
}
gh: Branch not protected (HTTP 404)
```
Captured 11 October 2026; time of capture and exit status not supplied with
the output.

Slot 2, screenshot: `WP-CA02-design-20261011-settings.png`, captured by
B. Struve on 11 October 2026; the system clock in the image reads
11 Oct 12:21. Full window, URL bar and system clock visible. The URL bar
reads `github.com/BeeStru/eu-ai-act-triage/settings/branches`, and the
Branch protection rules panel states "Classic branch protections have not
been configured".

**Executed.** 2026-10-11. In-sandbox attempt 12:05 BST; screenshot 12:21
BST per the image's clock; `gh api` output captured the same day, time not
supplied.

**Conclusion.** Design deficiency: the API returns "Branch not protected"
(HTTP 404) for `main` and the settings page states that classic branch
protections have not been configured, so no configured check stands between
a push and `main`. Scope limitation: both items address classic branch
protection; repository rulesets were not separately inspected.
