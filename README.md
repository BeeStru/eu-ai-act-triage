# EU AI Act deployer-readiness toolkit

The EU AI Act takes a risk-based approach: what an AI system is used for
determines its risk tier, and the tier determines the obligations. The same
model can be minimal-risk drafting marketing copy and high-risk screening
CVs, so an organisation deploying AI has to classify every distinct use, not
every model.

This toolkit is a set of instruments for that job: classify each use case
under the Act, produce a dated audit record per system that will stand up to
inspection, and carry the classification through into the model inventory
and vendor due diligence. Doing this by hand for one system is easy; doing
it consistently for two hundred is not, and that gap is what the toolkit
closes.

Under construction; first working release planned August 2026.
